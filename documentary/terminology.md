# Terminology list — consistent translation across all chapters

Shared across the whole *Nenjukku Neethi* documentary series. Preserve political/cultural
terms; transliterate + gloss rather than flatten. Add rows as new chapters introduce terms.

| Tamil | Preferred English | Handling |
|---|---|---|
| நெஞ்சுக்கு நீதி | *Nenjukku Neethi* (lit. "Justice for the Heart") | Keep title transliterated; gloss once |
| கலைஞர் | Kalaignar (lit. "the Artist") | Keep as honorific title, not translated |
| உடன்பிறப்பே / உடன்பிறப்புகள் | *Udanpirappē / udanpirappugal* | Transliterate; gloss "one born alongside me — kin/comrade" once |
| அறிஞர் அண்ணா | Arignar Anna | Keep; gloss "the scholar-leader C.N. Annadurai" once |
| தந்தை பெரியார் / ஈ.வெ. ராமசாமி | Thanthai Periyar / E.V. Ramasamy | Keep name; do not translate "Periyar" |
| சுயமரியாதை | self-respect (movement) | Standard English term |
| சமுதாய நீதி | social justice | Standard |
| முதலமைச்சர் | Chief Minister | Standard |
| காங்கிரஸ் | the Congress | Capital C |
| காலனி மக்கள் | colonial / subject peoples | — |
| வாழ்க்கை வரலாறு / சுயசரிதை | life-story / autobiography | Use "life-story" for the reflective sense, "autobiography" for the book |
| திருக்குவளை (திருக்கோளிலி) | Thirukkuvalai (also Thirukkolili) | Fixed spelling across series |
| திருவாரூர் | Thiruvarur | Fixed spelling |
| தஞ்சை மாவட்டம் | Thanjavur district | Fixed spelling |
| காவிரி | Cauvery | Use "Cauvery" (not "Kaveri") for consistency with site |
| மைசூர் | Mysore | Historical name as in source |
| பிறந்த ஆண்டு | "The Year of Birth" | Chapter-title translation, fixed |

**Rule:** when a term's meaning would shrink in translation (e.g. *udanpirappē*, *Kalaignar*,
*Periyar*), keep the Tamil/transliteration and gloss it **once** on first appearance.
