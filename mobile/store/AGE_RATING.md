# Age-rating worksheet

For the App Store Connect age-rating questionnaire. **App Store Connect calculates the final
rating from the answers — do not hard-code a number.** Apple has moved to a revised global
age-rating system (ratings such as 4+, 9+, 13+, 16+, 18+) with an updated questionnaire; confirm
the exact question wording in ASC at submission. The answers below are conservative and honest,
based on the app's actual content.

## What the content actually is
An archival political memoir (Tamil, 1924–2005) and letters. The prose refers to historical and
political events — including imprisonment, political conflict, and deaths/assassinations in
Tamil/Indian political history — in a **factual, textual, non-graphic** way. There is **no**
depicted graphic violence, no sexual content, no profanity as gratuitous language, no gambling,
no promotion of alcohol/drugs, no medical/treatment advice, no user-generated content, and no
in-app open web browser.

## Recommended answers
| Questionnaire category | Answer | Reasoning |
|---|---|---|
| Cartoon or Fantasy Violence | None | — |
| Realistic Violence | **None / Infrequent-Mild** | Historical political events (incl. deaths, imprisonment) are **referenced in prose**, not depicted graphically. Answer **None** if the category means depicted violence; if it captures textual references, answer **Infrequent/Mild**. Do not exaggerate. |
| Prolonged Graphic/Sadistic Realistic Violence | None | Not present |
| Sexual Content or Nudity | None | Not present |
| Profanity or Crude Humor | None | Formal memoir prose |

| Medical/Treatment Information | None | — |
| Unrestricted Web Access | **No** | Settings opens **specific** external pages (`/privacy`, `/support`, `/about`, site home) in the system browser; there is **no** in-app open/unrestricted web browser. |

| Contests | No | — |

## Expected outcome
With the above, ASC will most likely calculate a **low rating (4+ to 12+/13+ range)**. If
"Realistic Violence / Mature Themes" is answered **Infrequent/Mild** to cover the historical
references, expect roughly **12+/13+**; if answered **None** (violence depicted, not referenced),
expect lower. **Do not assert the final number here** — let the questionnaire compute it.
